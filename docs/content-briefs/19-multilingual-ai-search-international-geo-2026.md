## Original angle / contribution
1. "Query language selects the market" — the controlled-evidence version. Language gates local suppliers; location selects which market.
2. The three-tier system: official language → minority language → English. Each tier produces different citation behavior.
3. The instability finding: top recommendation changes across identical runs; instability is a system property, not a surface.
4. The ChatGPT English gravity: 2.6× over-indexing on English retrieval; bias at answer time, not training.
5. Translation gets you retrievable; native writing gets you cited. 2.3× mention rate for natively written vs MT mirrors.
6. The measurement blind spot: a visibility tracker running one language covers one market.
